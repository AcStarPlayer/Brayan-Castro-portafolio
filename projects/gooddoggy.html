Pet Community MERN Platform

GoodDoggy Community

Plataforma digital enfocada en gestión de mascotas, perfiles caninos, comunidad veterinaria, registro de mascotas, directorio veterinario, calendario de vacunación y experiencias sociales para dueños de mascotas.

Proyecto diseñado y desarrollado por Brayan Andrés Castro Márquez, Ingeniero de Software y Desarrollador Full Stack especializado en aplicaciones web modernas y experiencias digitales escalables.

Ver interfaces Tecnologías
CASE STUDY

Desarrollo del Proyecto

Objetivo del Proyecto

Desarrollar una plataforma social enfocada en mascotas y comunidad veterinaria, utilizando el stack MERN, implementando funcionalidades completas para usuarios y administración del sistema.

Funcionalidades Principales

Registro de mascotas, perfiles caninos, calendario veterinario, comunidad social, directorio veterinario y reportes de mascotas perdidas.

Arquitectura y Diseño

El sistema fue diseñado con una arquitectura Full Stack basada en MongoDB, Express, React y Node.js, utilizando una interfaz moderna, amigable y enfocada en interacción social para dueños de mascotas.

STACK TECNOLÓGICO

Arquitectura y Tecnologías

GoodDoggy Community fue desarrollado bajo una arquitectura Full Stack MERN, implementando tecnologías modernas enfocadas en escalabilidad, rendimiento, seguridad y experiencia de usuario.

Database

MongoDB

Base de datos NoSQL orientada a documentos, utilizada para gestionar mascotas, usuarios, veterinarias y publicaciones de forma escalable y flexible.

NoSQL Scalable JSON
Backend Framework

Express.js

Framework backend utilizado para construir APIs REST, manejar autenticación JWT, middleware y comunicación segura entre cliente y servidor.

REST API Middleware JWT
Frontend Library

React.js

Librería frontend utilizada para construir interfaces dinámicas, componentes reutilizables y flujos interactivos enfocados en experiencia de usuario moderna.

Components SPA UI/UX
Runtime Environment

Node.js

Entorno de ejecución utilizado para desarrollar la lógica del servidor, integración de APIs y procesamiento backend utilizando JavaScript.

Server JavaScript Backend
